Vehicle-to-grid, from the ECU to the back end.

No sockets, no clock, no async runtime — those are yours.

Four decisions

ISO 15118 is what a car and a DC fast charger speak while deciding whether to move 350 kW between them. One codebase for both roles and both generations, on a charge-point back end and a bare-metal controller alike.

01

Sans-I/O

Bytes and a timestamp in; bytes, events and deadlines out. A whole DC charging session runs as a unit test, with time as a variable.

02

no_std + alloc

The core builds for thumbv7em-none-eabihf. Every feature flag gates real code, so a DC-only vehicle controller compiles the DC message set and nothing else.

03

A wire format someone else agrees with

Every grammar and message is diffed against the EXI reference implementation, as documents and signature fragments, and captured sessions from real equipment re-encode byte for byte.

04

A decoder you can point at the internet

Every length is bounded by its schema facet before anything is allocated, nesting is capped, every decoder is fuzzed, and there is no unsafe.

Protocol, not policy

The engines own framing, decoding, the handshake, session ids, message ordering and the spec timers. Whether to authorize, which schedule to offer and how much current to deliver arrive as events you answer.

  • One engine shape everywhere. handle_input, poll_event, respond, take_transmit, poll_timeout — the same five calls for the charger, the vehicle, discovery and SLAC.
  • The ordering rules are data. One graph per protocol generation, shared by both roles. An ISO 15118-20 session speaks only the message set of the service it selected.
  • Including the rules about failing. A FAILED_* response ends the session and leaves only SessionStopReq; the drivers enter that state on their own.
  • And about stopping. Pause is not terminate, and renegotiating a schedule is neither.

What is implemented

From the powerline link coming up to the charge loop turning.

EXI — schema-informed, bit-packed Primitives, value string table, grammars, header, documents and fragments

And what is not

Named rather than implied.

Certificate revocation

Chains validate, but nothing here asks whether a certificate was withdrawn — no OCSP, no CRL. That answer belongs in the back end your station already talks to.

Transport bindings

No TCP, TLS or raw sockets. Bring rustls on a server and embedded-tls on an ECU; the examples show the glue.

DIN/TS 70121

Its message set is not included: there is no schema licence that permits generating from them. The handshake declines DIN by name, and the framing and timers carry a DIN codec of your own.
